# $TOMMY landing

Static Vercel-ready landing page for **$TOMMY — Mascot of Ascend**.

Before deployment, edit `public/config.js` and provide the official `contract`, `buyUrl`, `xUrl` and `telegramUrl`. Empty links intentionally remain hidden.

Deploy by importing this repository in Vercel and selecting `tommy-memecoin` as the **Root Directory**. No build command is required.
